# backend reading order

a beginner's guide to the backend codebase, ordered from simple to complex.
each new file builds on what came before, read them in order for the most coherent picture.

- **entry point**
    - `pyproject.toml`: project name, python version and dependencies.
    - `.python-version`: pins the python version uv uses.
    - `run.py`: starts the flask dev server on port 5000.
- **base**: database layer and wiring the application together
    - `constants.py`: password, name and word length rules.
    - `validation.py`: password and name checks, shared by players, rankings and admin usernames.
    - `settings.py`: env vars for the default admin and the sample ranking, with fallbacks, checked on startup.
    - `db.py`: the single way to open a database session anywhere in the codebase.
    - `models.py`: every database table as a python class plus `AuthAdmin`.
    - `migrations.py`: schema migrations, each idempotent, all run on every startup.
    - `__init__.py`: `create_app()`: logging, migrations, default admin, cookie policy, auth, errors, blueprints.
- **domain logic**: the business rules, no flask involved, tested standalone
    - `scoring.py`: set validity, match winner, games, points and standings tie-break sort.
    - `pairing.py`: the pairing algorithm, picks each round's opponents.
    - `stats.py`: computes a ranking's standings and match history from the database.
    - `rounds.py`: starts a round (pairs and creates its matches), closes it, saves a match result.
    - `seed.py`: sample ranking for the default admin: 20 players, 15 rounds, players leave and come back.
    - `admin.py`: creates an admin (name and password checks, optional seed), wipes an admin's own data.
- **route helpers**: shared utilities used by blueprints
    - `routes/helpers/decorators.py`: `require_admin()` prevents non admin users.
    - `routes/helpers/payload.py`: typed readers for json request fields, 400 on a wrong type.
    - `routes/helpers/ownership.py`: ranking getter, may return 404 or 403.
    - `routes/helpers/sorting.py`: alphabetical order ignoring accents, for players and rosters.
- **routes**: one blueprint per resource
    - `routes/auth.py`: login, logout and session check.
    - `routes/players.py`: list your own, create, and rename players.
    - `routes/rankings.py`: create/list rankings, start and close rounds.
    - `routes/participants.py`: list a ranking's active participants, add, and remove.
    - `routes/matches.py`: list a ranking's current round matches, enter or clear a match result.
    - `routes/standings.py`: computes and returns a ranking's current standings.
    - `routes/reset.py`: the default admin's reset, wipe and seed again.
- **tests**: live under `backend/tests/`, mirroring the `app/` structure
    - `tests/conftest.py`: fixtures (clients, 2 admins, 4 players, started ranking), db cleanup, request helpers.
    - `tests/test_scoring.py`: scoring rule tests, set/tiebreak validity, match winner, points, tie-break chain.
    - `tests/test_pairing.py`: pairing algorithm tests, window/tiering, construction, repair passes.
    - `tests/test_stats.py`: direct database tests for `compute_history` and `compute_standings`.
    - `tests/test_auth.py`: login, logout, session, cookie, bad input, timing-safe unknown user, `create_admin()`.
    - `tests/test_players.py`: player creation and name checks, renaming, own players listed alphabetically, ownership.
    - `tests/test_rankings.py`: ranking creation and name checks, `admin_id` filter, start and close rounds, ownership.
    - `tests/test_participants.py`: participant add/remove/reactivate, alphabetical roster, cross-admin ownership.
    - `tests/test_matches.py`: match endpoint tests, results, ownership, not found, editing locked after close.
    - `tests/test_standings.py`: standings endpoint tests, points, tie order, not-found.
    - `tests/test_seed.py`: seeded ranking with a fixed rng, round counts, results, active players, full standings.
    - `tests/test_reset.py`: reset access, wipe and reseed, other admins' data kept.
- **dev tools**
    - `create_admin.py`: creates a new admin account directly in the db, run by hand, no in-app route for it.
